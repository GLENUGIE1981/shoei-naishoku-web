# shoei-naishoku-web

作業納品書の入力フォーム（静的フロントエンド）。GitHub Pages で配信します。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | タブレット版の入力・履歴画面 |
| `mobile.html` | 文字を大きくしたスマートフォン版 |
| `gas-api.js` | サーバー呼び出しの共通処理と、起動時のアクセス確認 |
| `vendor/jsqr.js` | QR読み取りライブラリ（[jsQR](https://github.com/cozmo/jsQR) 1.4.0, Apache-2.0） |

ビルド不要です。編集したファイルをそのまま push すると Pages に反映されます。

## 開発メモ

- サーバー処理は別管理の Google Apps Script 側にあります。呼び出せる関数は
  `gas-api.js` の `FUNCS` に列挙してあり、**サーバー側の許可リストと一致させる必要があります**。
  片方だけに追加しても動きません。
- サーバーとの通信には `Content-Type: text/plain` を使っています。`application/json` に
  変えると通信が全て失敗します（理由は `gas-api.js` の冒頭コメント参照）。
- 画面は開いた直後にアクセス確認を行い、確認が済むまで中身を表示しません。
